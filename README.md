# Game By Vote

A game built with AI, where Instagram followers ([@gamebyvote](https://www.instagram.com/gamebyvote/)) vote on what it becomes.

**Play:** https://heeloo123.github.io/gamebyvote/

## Day 0
Mochi, a little critter you tap to make happy, in three art styles. Followers vote on the look:

- `styles/pixel.html` (A)
- `styles/cartoon.html` (B)
- `styles/clay.html` (C)

`index.html` lets players switch between them. Each file is self-contained; open any of them in a browser.

## Repo layout
- `styles/`: the playable game, one file per art style
- `assets/`: shared files (Press Start 2P font, SIL Open Font License)
- `video/`: the Reel pipeline, see `video/README.md`
- `reels/`: finished Reels, hosted here so the scheduler can fetch them
